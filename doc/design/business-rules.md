## 成績集計

### 対象・照合

- 現在の試合取得はチーム別 `games`。当年個人成績・選手詳細・個人成績一覧の一部は年による絞込を行いません。
- 試合番号は `(date文字列, 文書ID)` で昇順に並べて1から付与する処理を持ちます。同日複数試合は番号で区別します。
- 選手照合は ID 一致のほか、半角・全角空白除去後の名前の部分一致を許す処理があります。全処理で同一の照合規則ではありません。
- 試合詳細の多くの成績は手入力値と打席再集計値の `max` を使用します。両者の和ではありません。
- 個人成績一覧は現在の名簿に結び付く選手を対象とし、規定到達者の打率降順、その後に未到達者の打率降順で表示します。
- チーム成績は2020～2025年を固定データ、2026年以降を試合集計とします。年・区分で絞り、区分指定時は固定の過去成績を表示しません。

### 計算式

以下は現在の個人成績一覧・当年成績等で使う式です。分母が0の場合は0です。

| 指標 | 式 |
| --- | --- |
| 打率 AVG | 安打 / 打数 |
| 出塁率 OBP | (安打 + 四球 + 死球) / (打数 + 四球 + 死球 + 犠飛) |
| 塁打 | 単打 + 二塁打×2 + 三塁打×3 + 本塁打×4 |
| 長打率 SLG | 塁打 / 打数 |
| OPS | OBP + SLG |
| 得点圏打率 | 得点圏安打 / 得点圏打数 |
| 規定打席 | `ceil(round(打撃resultsのあるチーム試合数 × paPerGame, 6))` |
| 勝率 | 勝利 / (勝利 + 敗戦)。引分を分母に含めない |
| 投球回の実数 | 取得アウト / 3 |
| 投球回の表示 | `取得アウト // 3` + `.` + `取得アウト % 3`（例: 7アウト→2.1） |
| 防御率 ERA | 自責点 × 7 / 投球回（7イニング基準） |
| WHIP（現実装） | (被安打 + 四球 + 死球) / 投球回 |
| K/BB（現実装） | 奪三振 / (四球 + 死球) |

投手指標は `pitchers.py` で小数2桁に丸めます。一般的な指標と同じ名称でも、この実装では WHIP・K/BB に死球を含めます。投手名単位で集計し、投手の勝敗・セーブ・完封は現在加算しません。

旧キャッシュの出塁率は `(安打 + 四死球) / 打席` であり、上記の新試合集計の式とは異なります。結果コードの安打・打数判定も処理間で差があります。根拠: `stats/annual_tables.py`、`current_year.py`、`pitchers.py`、`teamstats.py`、`stats/batting_count.py`。

### 直近の調子

選手詳細では打席記録を日付単位でまとめ、直近5日分の安打/打数から判定します。同日ダブルヘッダーは1日としてまとまります。

| 直近打率 | 調子 |
| --- | --- |
| 0.400以上 | 絶好調 |
| 0.300以上0.400未満 | 好調 |
| 0.200以上0.300未満 | 普通 |
| 0.100以上0.200未満 | 不調 |
| 0.100未満 | 絶不調 |
| 有効打数なし | データなし。日程画面の名簿表示では普通に補正 |

根拠: `stats/player_form.py`、`routes/schedule.py:_roster_conditions`。JSON 生成時の `stats/recent_form.py` とは別処理です。

## 能力値

### 基礎数値と補正

`plus_*` を基礎数値に加えます。基礎値の上限・下限処理後に加算するため、最終値を再び100以内に抑える共通処理はありません。

| 能力 | 基礎値・採用条件 |
| --- | --- |
| ミート | `174 × 打率 + 14.5`。規定打席による補正時は `min(1, sqrt(打席/規定打席))` を掛け、打席等がないときは0.5倍。丸めて30～100 |
| ミートの年度選択 | 新試合の選手出場が6試合以上ならその成績。5試合以下は旧年度成績の2025年を優先、なければ末尾の年、旧年度がなければ旧打席集計 |
| パワー | 飛距離がある場合は `min(100, 飛距離) - 20 + 本塁打×2` を丸め0～100。出場数によって当該集計か旧年度本塁打を使用。飛距離がない場合は旧長打率の偏差値、算出できなければ50 |
| 走力 | 短距離タイムの逆向き偏差値 `T` から `T + 10 + (T-50)×0.5` を丸め0～100。算出できなければ50 |
| 肩力 | 遠投が正なら `ceil(遠投) - 10` を0～100、なければ50 |
| 守備力 | 50 |
| 捕球 | `50 - 失策×倍率` を0～100。主ポジション文字列に「外野手」があれば倍率3、それ以外は1 |

偏差値は `50 + 10×(値-平均)/標準偏差`、タイムの逆向きでは `(平均-値)` を使用します。短距離・長打率の標準偏差計算は有効データが3件以上の場合です。肩・打撃測定などの単位はフィールド名から推測せず、入力元と合わせて扱ってください。

年齢は生年月日（YYYY-MM-DD または YYYY/MM/DD）から計算し、解析できなければ25。表示用持ち点は `max(0, 40-年齢)`。これは補正 API が強制する割当上限ではありません。

根拠: `stats/ability_power.py`、`stats/prepare_frames.py`、`stats/player_shell.py`、`utils.py`。

### ランク

チャンスは得点圏打率−全体打率、対左は対左打率−全体打率で判定。対左打数が10未満なら差に `対左打数/10` を掛けます。全体打数15未満では両方Dです。

| 打率差の下限 | ランク |
| --- | --- |
| +0.250 | A |
| +0.150 | B |
| +0.050 | C |
| -0.050 | D |
| -0.150 | E |
| -0.250 | F |
| -0.250未満 | G |

盗塁: 8以上A、5以上B、2以上C、それ以外D。

走塁: `V = (長距離平均 - 本人長距離) × (本人短距離×4 - 本人長距離)`。V が0.55以上A、0.35以上B、0.10以上C、0以上D、-0.40以上E、それ未満F。必要な正のタイムがない場合D。

### 定量特殊能力

新試合の打席から再判定する処理では、全体15打数以上が以下の共通条件です。15打数未満では該当フラグを false にします。

| フラグ | 条件 |
| --- | --- |
| `t_pull` | 引張打率0.350以上、流打率0.250未満 |
| `t_chancemaker` | 走者なし打率0.300以上 |
| `t_nagashi` | 流打率0.350以上 |
| `t_koukaku` | 引張・流打率の両方が0.300以上 |
| `t_firststrike` | 0ストライク打率0.400以上 |
| `t_vsace` | 公式戦打率0.350以上 |
| `t_nebari` | 2ストライク打率0.300以上 |
| `t_bat4` | 4番打率0.300以上 |
| `t_katame` | 複数安打試合 / 安打のある試合 が0.250以上 |
| `t_infield` | 内野安打 / 全安打 が0.400以上 |
| `t_manrui` | 満塁打数2以上、満塁打率0.300以上 |
| `t_bunt` | 犠打5以上 |

右打者の引張方向は三・遊・左、流しは一・二・右。左打者は逆にします。内野方向は投・捕・一・二・三・遊です。分母0では打率0を使用します。

`t_sayonara` は選手詳細・能力一覧では `qual_sayonara` の定性フラグから設定します。特殊能力種類を追加する管理画面はありますが、追加種類のすべてが選手詳細の固定表示順へ自動追加される実装ではありません。

根拠: `stats/ability_ranks.py:apply_plate_abilities,apply_steal_rank,apply_run_rank,lit_special_abilities`、`routes/player_detail.py`、`routes/players.py`・`routes/abilities.py`・`routes/meeting.py`。

## キャッシュ・保存の整合性

- キャッシュ更新は旧名簿・旧記録と新試合を使い、チーム別ファイルへ直接保存します。定期ジョブや有効期限はありません。
- 従来打席の保存・更新・削除後に再集計します。能力補正 API 自体はキャッシュを再生成しません。
- 旧名簿が空なら集計を中断します。その他チームのキャッシュがなければ読取は空配列です。
- 日程・イベントは同じ poll を Firestore トランザクションで更新し、削除したキーが残らないよう poll 全体を置換します。
- 画像保存と Firestore 更新、名簿 ID 採番には一括整合性を保証する仕組みがありません。
